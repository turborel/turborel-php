# Installing

[Contents](README.md)

This chapter will tell what the driver needs, PHP 8.3 or later on a
64-bit build with the extension openssl, and zlib and bcmath if wanted,
and how to install it with Composer on Linux, macOS and Windows. The
package is not yet published on Packagist; until it is, the driver is
built from its repository, as [README.md](../../README.md) says. The
chapter is written as milestone M2 lands, when there is a connection to
install for.
