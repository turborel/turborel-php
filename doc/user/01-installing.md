# Installing

[Contents](README.md)

This chapter will tell what the driver needs, PHP 8.3 or later, 64-bit on Linux,
macOS or Windows, and how a program takes `turborel/turborel` in from
Packagist. No package is published until every Turborel driver is
done; until then the driver is built from its source, as the
repository's
[README](https://github.com/turborel/turborel-php/blob/main/README.md)
says. The chapter is written with the standard API, at milestone M7, and
again when the packages are published.
