# The Connection Class

[Contents](README.md)

This page will describe the PDO-style connection: how it is made from a `turborel://` URI or the driver's settings, its attributes and its transactions, part of the driver's
standard interface, an API in PDO's shape, written in PHP; a real PDO driver would need a C extension, so it is not `\PDO` itself. It is filled at milestone M7.
